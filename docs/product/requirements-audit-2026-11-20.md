## 4. Definitions used (confirm or correct)

1. **Truck spend** = trip expenses + transporter invoices linked to the trip. Purchase cost is excluded because it belongs to procurement; quoted compartment haulage is excluded until it becomes an invoice.
2. **Loading cycle** = a trip. Spend is attributed to the truck on the primary assignment, falling back to any assignment for historical trips.
3. **Daily spend** uses `trip_expenses.incurred_on` and `transporter_invoices.invoice_date`. An expense with no date uses the trip departure date, then the trip creation date.
4. **Loading costs** shows Loading and Other separately; every other type is included in the trip statement only. This keeps the loading view short while the detailed breakdown remains available.
5. **Role scope** follows the table above. If the Director should not manage people or settings, those two permissions can be removed.

## 5. Naming codes — proposal, not implemented

The app still requires supplier, depot, product, customer, batch, purchase-order and sales-order codes. Suggested change:

| Record | Generated example | Rule |
|---|---|---|
| Supplier | `SUP-2026-7K2M` | Generated server-side when blank; manual entry still allowed |
| Depot | `DEP-2026-4F9Q` | Same |
| Product | `PRD-2026-2H6T` | Same |
| Customer | `CUS-2026-8R3N` | Same |
| Batch | `BAT-20261120-5J2P` | Same, date-prefixed |
| Purchase order | `PO-20261120-9D4W` | Same |
| Sales order | `SO-20261120-3C7V` | Same |
| Truck registration, driver licence, vehicle plate | — | Stay manual: real-world identifiers |

Uniqueness is guaranteed by the existing per-tenant unique constraints; a collision would retry with a new suffix. This is a contained change across seven forms/actions but was left for approval because it changes user-visible identifiers.

## 6. Remaining gaps and clarifications

- **Date range filters** for truck spend are not implemented; the view uses the latest 100 trips, 500 expenses and 500 invoices.
- **Per-customer statement/receivables** is not implemented; the customer page shows orders and values, not outstanding balances.
- **Role-specific home pages** are not implemented; roles control permissions and navigation, not a tailored dashboard.
- **Code autogeneration** awaits approval of the pattern above.
- **Spend inclusion of purchase cost** is a business choice; current view excludes it.
- **Other expense categories** are limited to fuel, toll, loading, driver allowance, maintenance and other. More categories need a decision and possibly a lookup table.
